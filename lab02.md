## Git и GitHub - в чём разница
Git - локальная система контроля версий, работает на моём компьютере.
GutHub - облачный сервис для хранения репозиториев и совместной работы.
Git может работать без GitHub, а GitHub без Git - нет.
## Использованные команды
- "git status" - показывает состояние рабочей папки и индекса.
- "git diff" - разница между рабочей папкой и индексом.
- "git diff --staged" - разница между индексом и последним коммитом.
