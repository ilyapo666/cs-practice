#Git: заметки
## Рабочая папка(working directory)
Это текущее состояние файлов на диске, которые я редактирую.
Изменения здесь еще не зафиксированы Git.
## Индекс(staging area)
Промежуточная область, куда я добавлю изменения командой "git add".
То, что попало в индкс, войдет в следующий коммит.
## Коммит(commit)
Зафиксированный снимок состояния индекса с сообщением.
Коммит - это неизменяемая точка в истории проекта.
## Git и GitHub - в чём разница
Git - локальная система контроля версий, работает на моём компьютере.
GutHub - облачный сервис для хранения репозиториев и совместной работы.
Git может работать без GitHub, а GitHub без Git - нет.
## Использованные команды
- "git status" - показывает состояние рабочей папки и индекса.
- "git diff" - разница между рабочей папкой и индексом.
- "git diff --staged" - разница между индексом и последним коммитом.
## Ветки
Ветка - это подвижный указатель на коммит.
При новом коммите указатель ветки автоматически сдвигается вперёд.
Слияние(merge) объединяет изменения из одной ветки в другую,
создавая при необходимости коммит слияния.
