### Разница между git diff, git show и git log
- **git diff**: показывает разницу между рабочей директорией и индексом(или между коммитами)
Отвечает на вопрос: "Что изменилось, но еще не закоммичено?".
- **git show**: Показывает полную информацию о конкретном объекте Git (коммите, теге, дереве.) 
Для коммита показывает метаданные (автор, дата) и сам diff изменений.
- **git log**: Показывает историю коммитов в обратном хронологическом порядке (список коммитов с их кешами и сообщениями).
## Что нашли log -S и blame
- **log -S"def"**: Находит коммиты, в которых количество вхождений строки "def" изменилось (добавление или удаление).
Это позволяет найти, когда была добавлена та или иная функция.
- **blame**: Показывает построчно, какой коммит и какой автор последний раз меняли каждую конкретную строку файла. 
Помогает найти виновника изменений.
